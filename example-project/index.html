Проєкт на GDevelop: Дівчинка в навушниках🎮

Опис проєкту

Це легка 2D-гра, у якій гравець керує дівчинкою в навушниках, яка насолоджується музикою й намагається уникнути метеоритів-котиків. Мета гри — ухилятися від зіткнень якомога довше. Гра розроблена для розваги й тренування реакції.

Використані технології

  • GDevelop — для створення гри
  • HTML5 — для інформаційної сторінки
  • CSS — для стилізації сторінки
  • Pixel Art — для графічного оформлення

Керування грою

  • Стрілка вліво — рух вліво
  • Стрілка вправо — рух вправо
  • Мобільна версія: натискання зліва/справа на екрані

Графіка та ліцензія

Для створення гри використано:

  • Безкоштовні спрайти з відкритою ліцензією CC0 або CC BY
  • Частина графіки створена самостійно (див. нижче)

Авторські елементи

Деякі ігрові елементи були створені вручну:

  • Спрайт дівчинки з навушниками — намальовано самостійно
  • Анімація "переляку" — створена вручну на основі базового образу
  • Фони та кнопки оформлення — створені автором проєкту
